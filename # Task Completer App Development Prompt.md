# Task Completer App Development Prompt

## Overview
Create a competitive task completion application where users can assign tasks to each other. The app will rank users based on their performance, speed, and consistency in completing tasks.

## Key Features
- Users can assign tasks to other users
- Users can view their assigned tasks
- Users can view tasks assigned to other users
- Performance tracking and ranking system
- User statistics dashboard

## Technical Requirements
- Next.js framework
- TypeScript for type safety
- CSS for styling (no Tailwind)
- Supabase for backend database
